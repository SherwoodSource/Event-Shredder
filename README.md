Event-Shredder
==============

Event Shredder Repository. This batch application is open source and is developed to erase logs that are not needed.

### Updates
- **v1.1**: Updated for full compatibility with Windows 10 and Windows 11. Modernized the UI and improved the log clearing process.

If you know of logs that are not currently covered by this app please add to the repository! "Project moved to SourceForge"
https://sourceforge.net/projects/eventshredder/
